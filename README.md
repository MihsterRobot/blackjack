# Blackjack

A command-line implementation of the classic Blackjack card game written in Python.

One human player competes against an automated dealer. The dealer follows standard Blackjack rules, hitting on 16 or below and standing on 17 or above. The game tracks each player's bankroll and winnings across rounds until the deck is exhausted or one player runs out of money.

Requires Python 3.10 or later.

---

## Getting started

```bash
git clone https://github.com/MihsterRobot/blackjack.git
cd blackjack
python main.py
```
